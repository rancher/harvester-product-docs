= Volume Hotplug
:description: Add a hot-plug volume to a running virtual machine by going to the Virtual Machines page, selecting the virtual machine, choosing Add Volume
:revdate: 2026-11-26
:page-revdate: {revdate}

{harvester-product-name} supports adding hot-plug volumes to a running virtual machine through the UI or by updating the `VirtualMachine` specification.

[NOTE]
====
When adding a hot-plug volume directly to a `VirtualMachine` specification (such as via YAML, API, Terraform or GitOps), set `hotpluggable: true` on the volume entry. If `hotpluggable: true` is omitted, the volume does not hot-plug immediately and the virtual machine enters the `RestartRequired` state (`RestartRequired=True`) until restarted.
====

[IMPORTANT]
====
In testing on {harvester-product-name} v1.9.0 (KubeVirt v1.8.4), hot-plugging with `hotpluggable: true` was observed on both `scsi` and `virtio` buses. Confirm bus and guest operating system compatibility for your workload before rolling out changes to production.
====

== Adding Hot-Plug Volumes to a Running Virtual Machine

The following steps assume that you have a running virtual machine and a ready volume:

. Go to the *Virtual Machines* page.
. Find the virtual machine that you want to add a volume to and select *⋮ -> Add Volume*.
+
image::vm/add-volume-button.png[Add Volume Button]
+
. Enter the *Name* and select the *Volume*.
. Click *Apply*.
+
image::vm/add-volume-panel.png[Add Volume Panel]
