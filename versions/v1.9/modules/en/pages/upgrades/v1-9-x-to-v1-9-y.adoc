== General Information

An *Upgrade* button appears on the *Dashboard* screen whenever a new SUSE Virtualization version that you can upgrade to becomes available. For more information, see xref:upgrades/upgrades.adoc#_start_an_upgrade[Start an upgrade].

For information about upgrading SUSE Virtualization in air-gapped environments, see xref:upgrades/upgrades.adoc#_prepare_an_air_gapped_upgrade[Prepare an air-gapped upgrade].

=== Failed Live Migrations Block Upgrades by Default

When you upgrade to v1.9.1 or later, SUSE Virtualization does not shut down a virtual machine if its live migration fails during the pre-drain phase of a node upgrade. The virtual machine keeps running, and the upgrade waits while the migration is retried.

[CAUTION]
====
The upgrade remains blocked until the live migration succeeds or the virtual machine is stopped. No timeout applies. For more information, see xref:upgrades/upgrades.adoc#_unblocking_a_waiting_upgrade[Unblocking a Waiting Upgrade].
====

To have SUSE Virtualization shut down these virtual machines instead, set the `shutdownVMOnMigrationFailure` field of the xref:storage/storage.adoc#_upgrade_config[`upgrade-config`] setting to `true` before starting the upgrade. The virtual machines remain stopped after the upgrade, and you must start them manually. For more information, see xref:storage/storage.adoc#_keeping_the_automatic_shutdown_behavior[Keeping the Automatic Shutdown Behavior].
