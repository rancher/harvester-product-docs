== Configuration and Authentication File Security
:revdate: 2026-09-29
:page-revdate: {revdate}

To harden your {harvester-product-name} cluster, you must verify and enforce strict file ownership and permission controls across all nodes. System configuration files govern storage, networking, and security secrets, while authentication files (such as keys, certificates, and tokens) establish cluster identity. Restricting access to these critical files prevents non-privileged users or compromised processes from altering system settings, exposing sensitive data, or causing cluster instability.

== Auditing file system permissions

Verify that the permissions of the files and directories in the table below are correct using the following commands:

[,shell]
----
cd <PATH>
ls -l
----

|===
| Path | Object | Owner and Group | Permission

| `/etc/rancher/rke2`
| Files
| `root:root` (`0:0`)
| `0600`

| `/var/lib/rancher/rke2/agent`
| Subdirectories and files
| `root:root` (`0:0`)
| See <<#_rke2_server_agent_permissions>>.

| `/var/lib/rancher/rke2/bin`
| Files
| `root:root` (`0:0`)
| `0750`

| `/var/lib/rancher/rke2/data`
| Directory and files
| `root:root` (`0:0`)
| `0750`

| `/var/lib/rancher/rke2/server`
| Subdirectories and files
| `root:root` (`0:0`)
| See <<#_rke2_server_agent_permissions>>.
|===

For example, to verify the permissions of the primary RKE2 (server and agent) configuration files and cluster kubeconfig files, run the following commands:

[,shell]
----
cd var/lib/rancher/rke2
ls -l
----

== Mitigating insecure file system permissions

. Set the correct permissions for insecure files and directories.

** Files in `/etc/rancher/rke2`
+
[,shell]
----
cd /etc/rancher/rke2
chmod 0600 ./*
chown root:root ./*
ls -l
----

** Files in `/var/lib/rancher/rke2`
+
[,shell]
----
cd /var/lib/rancher/rke2
chown root:root ./*
ls -l
----

** Subdirectories and files in `/var/lib/rancher/rke2/agent`
+
[,shell]
----
cd /var/lib/rancher/rke2/agent
chown root:root ./*
chmod 0700 pod-manifests
chmod 0700 etc
find . -maxdepth 1 -type f -name "*.kubeconfig" -exec chmod 0640 {} \;
find . -maxdepth 1 -type f -name "*.crt" -exec chmod 0600 {} \;
find . -maxdepth 1 -type f -name "*.key" -exec chmod 0600 {} \;
ls -l
----

** Files in `/var/lib/rancher/rke2/bin`
+
[,shell]
----
cd /var/lib/rancher/rke2/bin
chown root:root ./*
chmod 0750 ./*
ls -l
----

** `/var/lib/rancher/rke2/data` directory
+
[,shell]
----
cd /var/lib/rancher/rke2
chown root:root data
chmod 0750 data
ls -l
----

** Files in `/var/lib/rancher/rke2/data`
+
[,shell]
----
cd /var/lib/rancher/rke2/data
chown root:root ./*
chmod 0750 ./*
ls -l
----

** Files and subdirectories in `/var/lib/rancher/rke2/server`
+
[,shell]
----
cd /var/lib/rancher/rke2/server
chown root:root ./*
chmod 0700 cred
chmod 0700 db
chmod 0700 tls
chmod 0750 manifests
chmod 0750 logs
chmod 0600 token
ls -l
----

. Edit the RKE2 server configuration file (`/etc/rancher/rke2/config.yaml`) on all nodes and add the following:
+
[,yaml]
----
write-kubeconfig-mode: "0600"
----
+
After updating the configuration file, restart the RKE2 server.
+
[,shell]
----
systemctl restart rke2-server
----

. Set the correct permission for the Container Network Interface file.
+
Example:
+
[,shell]
----
cd /var/lib/cni/networks
chmod 600 <filename>
ls -l
----
