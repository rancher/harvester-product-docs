Rancher vCluster (Experimental)

rancher-vcluster es un complemento experimental. No está incluido en la ISO, pero puedes descargarlo desde el experimental-addons repositorio. Para más información sobre características experimentales, consulta Etiquetas de Características.

El complemento rancher-vcluster te permite ejecutar Rancher como una carga de trabajo en el clúster subyacente SUSE Virtualization y se implementa utilizando vCluster.

El complemento ejecuta un clúster K3s anidado en el espacio de nombres rancher-vcluster y despliega Rancher en este clúster.

Durante la instalación, el ingreso para Rancher se sincroniza con el clúster SUSE Virtualization, permitiendo a los usuarios finales acceder a Rancher.

Instalando el complemento

Si estás utilizando el archivo kubeconfig de SUSE Virtualization, puedes instalar el complemento ejecutando el siguiente comando:

kubectl apply -f https://raw.githubusercontent.com/harvester/experimental-addons/main/rancher-vcluster/rancher-vcluster.yaml

Configurando el complemento

Después de la instalación, configura el complemento utilizando la interfaz de usuario SUSE Virtualization.

  1. Ve a Complementos Avanzados →.

  2. Localiza el complemento rancher-vcluster, y luego selecciona ⋮ → Editar Configuración.

  3. En el campo Nombre de host, introduce un registro DNS válido que apunte al VIP SUSE Virtualization. Esto es esencial ya que el ingreso del vcluster se sincroniza con el clúster padre SUSE Virtualization. Se utiliza un nombre de host válido para filtrar el tráfico de ingreso hacia la carga de trabajo del vcluster.

  4. En el campo Contraseña de inicio, introduce la contraseña de inicio para el nuevo Rancher desplegado en el vcluster.

Una vez que el complemento esté desplegado, Rancher puede tardar unos minutos en estar disponible.

Luego puedes acceder a Rancher a través del registro DNS del nombre de host que proporcionaste.

Consulta Rancher Integración para más información.

El complemento se despliega en un vcluster Statefulset que utiliza un PVC de Longhorn llamado data-rancher-vcluster-0.

Cuando desactivas el complemento, el PVC permanece en el espacio de nombres rancher-vcluster. Si vuelves a habilitar el complemento, el PVC se reutiliza y se restaura el estado anterior de Rancher.

Si deseas borrar los datos, asegúrate de que el PVC esté eliminado.
